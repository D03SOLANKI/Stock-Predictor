# TASK: Post-Backtest Error Analysis — Why the Screener Hit and Missed

## Purpose and scope boundary

The walk-forward backtest already established the system's precision (8.05% vs 4.40%
baseline) and PnL. **This task does not re-run or re-litigate that number.** This
task explains *why* — what separates the hits from the misses, and what separates
both from the moves this system structurally cannot catch. The output should be a
diagnosis, not a new leaderboard.

## Step 0 — Scope the sample (do not attempt "all days")

Full causal reconstruction across 501 days × 97 stocks is not feasible at real
fidelity and will produce shallow, templated write-ups if forced. Use this sample
instead:

1. **All 87 already-logged out-of-sample trades from the existing backtest** — these
   are already PIT-clean and outcome-known. This is Tier 1 and mandatory.
2. **A stratified random sample of 30 trading days** from the out-of-sample test
   period (2026-03-19 to 2026-09-16), independent of the 87 trades above. For each
   sampled day, pull the actual top gainers (+5% or more) in the 97-stock universe
   that the screener did **not** flag as a candidate at all — these are the true
   false negatives the backtest never scored, because the stock never entered the
   candidate pool. This is Tier 2, also mandatory.
3. If time/budget allows, expand Tier 2 to more days — state the final sample size
   used and why, so the result's statistical weight is honest and stated up front.

Do not silently shrink the sample without saying so. If a full 30-day Tier 2 sample
isn't completed, report the actual number analyzed and flag the report as partial.
